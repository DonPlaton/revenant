How Revenant brings a workspace back

CRASH → REVIVE IN FOUR STEPS
01

The machine dies

Nine agent sessions across nine directories go down with the terminal. Each one holds hours of context.

02

Transcripts outlive the crash

The registry of running sessions is wiped on the next start. The conversation files are not — they are the durable record.

sessions/<pid>.json projects/<slug>/<id>.jsonl history.jsonl
03

You pick a window

Drag from six hours to ninety days. The list refilters live, newest first, with the last prompt of each session.

6h1d7d30d90d
04

REVIVE

One tab per session, each already cd-ed into its directory and resumed at the right conversation.

REVIVE 9
WHAT IT READS Three files on disk. Nothing is ever written back.
~/.claude/sessions/*.json

One file per running session: pid, directory, name. Cross-checked against the live process table.

PRUNED ON STARTUP
~/.claude/projects/*/*.jsonl

The conversations themselves. Directory, branch and version come from the first records of each file.

SURVIVES A CRASH
~/.claude/history.jsonl

Every prompt you typed, with its session id — turn counts and previews without parsing gigabytes.
