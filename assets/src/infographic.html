How Revenant brings a workspace back

FOUR STEPS
01

The machine dies

Nine agent sessions across nine directories go down with the terminal. Each one holds hours of context you would rather not retype.

02

Transcripts outlive the crash

The registry of running sessions is pruned the next time the agent starts. The conversation files are not, so they are what Revenant reads.

sessions/<pid>.json projects/<slug>/<id>.jsonl history.jsonl
03

You pick how far back

Drag the caret from six hours back to everything on disk. Sessions hang off the time axis, newest first, each with its name or the last thing you said to it.

What it reads Claude Code's three files. Nothing is ever written back.
sessions/*.json

One file per running session. Checked against the process behind it, so a pid that another program has taken over does not count.

projects/*/*.jsonl

The conversations. Directory, branch and version come from the first records of each file. Codex keeps its rollouts in folders by date.
